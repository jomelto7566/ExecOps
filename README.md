## ✨ What ExecOps Does

ExecOps is a desktop-ready web app for managing Ansible playbooks. It helps you track playbook runs, view live output, and keep your automation work in one place.

Use it to:

- Start and monitor playbook runs
- Watch execution logs as they happen
- Organize common Ansible tasks
- Keep a clear view of your automation jobs
- Work from a simple dashboard instead of scattered tools

## 🧭 Main Features

### 📊 Dashboard View
See your playbook activity in one place. The dashboard gives you a clean view of jobs, status, and recent runs.

### 🔴 Live Execution Streaming
Watch Ansible output as it runs. This helps you track progress without switching windows.

### 🗂️ Playbook Tracking
Keep your playbooks grouped and easy to find. Use the dashboard to follow what runs, when it ran, and how it ended.

### 🧰 DevOps-Friendly Layout
The layout fits common automation work. It keeps key actions easy to reach and avoids clutter.

### 🎨 Simple Interface
The app uses a clear screen layout with modern UI parts from shadcn/ui and Tailwind CSS. That keeps the interface easy to scan.

## 🚦 How to Use ExecOps

1. Open ExecOps.
2. Sign in if the app asks for access.
3. Go to the playbook area.
4. Pick the playbook you want to run.
5. Start the run.
6. Watch the live output on screen.
7. Review the result when the job finishes.
8. Return to the dashboard to check other runs.
